# 消息与文件接入

## 同一 QQ 客户端插件（实验）

正常 QQ → 本机接收端 → SQLite 原文 → 可选模型分析。仅接收绑定账号与选定群的新消息。Mac QQ 7.0.3 的原型已经验证一条真实消息的完整流程，其他版本与 Windows 尚需适配。详见 [插件说明](NATIVE-PLUGIN.md)。

## 文件夹监听

在“自动接入”添加专用资料目录，后台每 10 秒扫描新文件和变化，不递归子目录，不读取 QQ 加密聊天库。取消监听不删除已导入内容。

## OneBot / NapCat 高级接入

项目保留本机 WebSocket 与 HTTP OneBot 接收能力，用于用户自行部署的兼容服务。主账号同时登录另一份桌面 QQ / NapCat 可能造成会话冲突，默认不启用这条路线，不自动部署容器。

若使用该方式，用户自行配置本机地址、Token，完成登录并勾选群。HTTP 端点为 `/api/onebot`，要求 Bearer Token 或 HMAC 签名；不要向公网开放该端口。群文件事件仅保存元数据，不能据此下载文件。

与 QQ 登录、风控、掉线及客户端升级有关的行为依赖第三方服务，不能承诺消息无损或永久兼容。
