# 使用流程

日常入口是桌面应用 **QQmanager**。双击打开；关闭窗口后仍在托盘运行，完整退出需使用菜单。

1. 导入聊天 TXT / JSON / CSV，或导入文件、设置资料文件夹监听。新安装没有真实聊天数据，可选择“用示例体验”。
2. 在“关注与设置”填入自己的模型地址、模型名和 API Key，点击“保存、测试并启用”。未启用模型时仍能使用本地规则和搜索。
3. 需要自动接入时，在“自动接入”填入自己的 QQ 账号和目标群号并保存。Mac 可从应用菜单打开插件助手，正常退出 QQ 后授权安装，再打开 QQ。
4. “重要信息”查看模型和规则结果；“原始记录”查看原文及分析状态；“文件资料”搜索资料。
5. 将确有需要的事项加入待办，确认北京时间和提醒时间。模型不会自动替你确认任务。

电脑休眠、关机、QQ 掉线或退出后台服务时，无法持续收集。QQ 客户端插件 0.1.6 会在恢复后核对已选群的可用记录，补收启用期间遗漏的消息，并沿用附件处理设置。

Windows 桌面功能与 Mac 共用代码；QQ 自动接入仍需要兼容的第三方加载器，尚未实机验证。参见 [桌面说明](DESKTOP.md) 和 [QQ 插件说明](NATIVE-PLUGIN.md)。
