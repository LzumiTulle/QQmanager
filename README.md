# QQmanager

把热闹的群聊整理成有原文依据的通知、待办和资料。支持 **macOS / Windows 桌面应用**、聊天与文件导入、全文搜索，以及 DeepSeek / OpenAI 兼容接口。

**[下载安装包](https://github.com/LzumiTulle/QQmanager/releases)** · [Windows 开发同步与交接存档](docs/QQmanager-Windows-Guide-zh-CN.txt) · [桌面使用与构建](docs/DESKTOP.md) · [QQ 插件说明](docs/NATIVE-PLUGIN.md) · [隐私与安全](SECURITY.md)

## 安装与使用

- **Mac**：下载对应芯片的 `.dmg`，拖入“应用程序”，双击 QQmanager。
- **Windows x64**：下载 `.exe` 安装器，双击完成当前用户安装，随后从桌面或开始菜单打开。
- 桌面外壳使用 Tauri，Mac 使用系统 WebKit，Windows 使用 WebView2。安装包内置 Python 服务。Windows 本地接入版使用电脑上已登录的 QQ，首次启动和账号接入都无需 Docker。Mac 的托管扫码方式使用本机容器引擎。
- 关闭窗口后仍在菜单栏 / 托盘运行。点击托盘图标重新打开；托盘菜单可关闭“登录系统后后台启动”或彻底退出。
- 首次启动默认启用登录后后台启动，可随时关闭。系统未登录、休眠、关机时不能实时收集。

> 本次 Windows 版本为 **0.4.2 试用版**。公开安装包尚未配置商业代码签名和 Apple 公证，系统可能要求确认开发者来源。不要关闭系统安全保护。安装桌面应用与接入 QQ 是两个步骤：第三方 QQ 插件需要单独授权，不能承诺所有 QQ 版本一键兼容。

## 界面

日程表将课程、考试和个人计划放在一周内查看。点击空档的「＋」可输入新的安排，也可以选择已有待办。事项页的「全部事项」汇总待确认、待完成和已完成记录，支持从原事项查看消息、附件，以及拆分和合并来源。

点击右上角「刷新」可复查历史消息。页面先显示本地复查的条数，再显示这次重新识别的处理进度、等待原因和完成结果。手动确认和安排的记录会保留。


## 功能

- 导入 TXT / JSON / CSV 聊天记录，保留发送者、群、时间和原文。
- 索引文本、DOCX、文字型 PDF；按文件名或正文搜索。
- 本地规则识别重要消息；可选大模型提取通知、待办、资料，保留逐字引用。
- 运势、机器人游戏、寒暄及缺少有效信息的福利播报会被过滤；原始记录仍可搜索。同一事项的补充、催办、附件和变更归入同一个事项，保留每次发送的原文。编号明确的考试按周整理，其他事项结合本地规则与已启用模型的同群标题归并；不跨账号或群聊自动合并。旧分析可在模型设置中点击“按新规则整理已有消息”重新检查。
- 调课通知关联个人课表，逐次列出原日期/节次、新日期/节次和教室；用户确认后同步课表与主页日历。橙色待确认、蓝色已调整，支持原文查看和撤销。仅修改涉及的课程日期，不改整学期。匹配不明、通知更新和时间冲突会提示；重复转发不会重复应用。
- 自定义关注词、收藏、忽略、原文追溯。
- 确认提醒时间后建立待办，站内与桌面提醒。
- 文件夹自动监听；原文去重，模型任务持久化、重试和调用次数限制。
- 实验性 QQ 同客户端插件：复用日常 QQ 登录，将指定群的新消息传给本机服务。

### QQ 自动收集的实际边界

Mac QQ **7.0.3-54395 / Apple Silicon** 上已验证插件加载、账号匹配，以及真实群消息的“收集 → 入库 → DeepSeek 分析 → 原文引用”。尚未完成长期稳定性、所有群或所有消息类型覆盖测试。

Windows 10/11 x64 桌面应用可独立使用导入、搜索、待办与模型配置。菜单提供选择 LiteLoaderQQNT 用户目录、安装本项目插件并配对的入口，无需另装 Python。**Windows QQ 自动接入仍依赖用户已有的兼容 LiteLoaderQQNT 环境，未完成实机验证**；不附带 QQ 二进制、登录组件、校验补丁或 DLL。不要把“Windows 安装包构建通过”等同于“Windows QQ 插件已验证”。

客户端插件 0.1.6 会在 QQ 登录后自动补收已选群中尚未入库的消息。首次补收从该账号、该群最后一条已入库消息接起；本地没有记录时从启用时起算，取消后重新勾选则从重新授权时起算，按群保存进度并去重，范围取决于 QQ 能读取的记录。插件 0.1.5 起可获取所选群的图片和文件（单个最多 20 MB），本机 OCR 提取图片文字，保留原图和原始消息。明确的通知、时间和考试表格优先在本机识别。需要模型辅助时发送脱敏文本片段或表格结构。旧记录仅尝试补取已收集消息的附件。QQ 更新可能使插件失效，可通过 Mac 插件助手恢复原始入口。

## 隐私

数据保存在本机 SQLite 和资料目录。默认不启用云端分析；启用后，复杂通知会向你配置的模型服务发送脱敏片段，必要时附一条相关前文。模型 Key 不进入 QQ 插件。不要将数据目录、密钥、QQ 会话或真实聊天日志上传到仓库。

提醒和 AI 判断仅供辅助，提取的待办与日期需要用户确认。

## 开发

```sh
python3 -m venv .venv
# Windows: .venv\Scripts\python.exe；Mac: .venv/bin/python
.venv/bin/python -m pip install -r requirements-build.txt
npm ci
npm start
```

也可单独运行 `python run.py`，浏览器访问 `http://127.0.0.1:8765`。服务只监听本机回环地址。

```sh
python -B -m unittest discover -s tests
node --test tests/*.test.cjs
python scripts/desktop/build_backend.py
python scripts/desktop/smoke_backend.py
# macOS 额外构建插件助手
python scripts/build_mac_installer.py
npm run dist:mac
# Windows 在 Windows 上构建
npm run dist:win
```

GitHub Actions 自动在 macOS / Windows 构建并测试，提供安装包和 SHA-256 校验文件；版本标签生成草稿 Release，核验后发布。
